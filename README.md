# Pronomes
Pronome é a palavra que **substitui ou acompanha um substantivo**, evitando repetições e indicando pessoas, objetos, lugares ou ideias.

Exemplos:

* **Maria** chegou cedo. **Ela** trouxe os livros.

  * "Ela" é um pronome que substitui "Maria".

* **Meu** caderno está na mochila.

  * "Meu" é um pronome que acompanha o substantivo "caderno", indicando posse.

Os principais tipos de pronomes são:

* **Pessoais:** eu, tu, ele, ela, nós, vós, eles, elas.
* **Possessivos:** meu, tua, nosso, sua.
* **Demonstrativos:** este, esse, aquele.
* **Indefinidos:** alguém, ninguém, tudo, alguns.
* **Relativos:** que, quem, cujo.
* **Interrogativos:** quem, qual, quanto.

Em resumo, o pronome serve para **substituir ou acompanhar o nome (substantivo)**, tornando a comunicação mais clara e evitando repetições.

## 1. Pronomes pessoais (Personal Pronouns)

São os mais importantes para começar.

| Português                    | Inglês   |
| ---------------------------- | -------- |
| Eu                           | **I**    |
| Você                         | **You**  |
| Ele                          | **He**   |
| Ela                          | **She**  |
| Ele/Ela (objetos ou animais) | **It**   |
| Nós                          | **We**   |
| Vocês                        | **You**  |
| Eles/Elas                    | **They** |

Exemplos:

* **I** am Marcos. (Eu sou Marcos.)
* **She** is my friend. (Ela é minha amiga.)
* **They** are engineers. (Eles são engenheiros.)

---

## 2. Pronomes possessivos (Possessive Pronouns)

Substituem um substantivo indicando posse.

| Português | Inglês     |
| --------- | ---------- |
| O meu     | **Mine**   |
| O seu     | **Yours**  |
| O dele    | **His**    |
| O dela    | **Hers**   |
| Ele/Ela (objetos ou animais)    | **Its**   |
| O nosso   | **Ours**   |
| O deles   | **Theirs** |

Exemplos:

* This book is **mine**.
* The house is **theirs**.

---

## 3. Pronomes objeto (Object Pronouns)

São usados quando recebem a ação do verbo.

| Pronome sujeito | Pronome objeto |
| --------------- | -------------- |
| I               | **Me**         |
| You             | **You**        |
| He              | **Him**        |
| She             | **Her**        |
| It              | **It**         |
| We              | **Us**         |
| They            | **Them**       |

Exemplos:

* She called **me**.
* I saw **him**.
* They invited **us**.

---

## 4. Adjetivos possessivos (Possessive Adjectives)

Apesar do nome, muitos livros os apresentam junto com os pronomes.

| Português          | Inglês    |
| ------------------ | --------- |
| Meu                | **My**    |
| Seu                | **Your**  |
| Dele               | **His**   |
| Dela               | **Her**   |
| Dele/Dela (objeto) | **Its**   |
| Nosso              | **Our**   |
| Deles              | **Their** |

Exemplos:

* **My** car.
* **Your** computer.
* **Their** house.

---

## 5. Pronomes demonstrativos (Demonstrative Pronouns)

| Inglês | Português                   |
| ------ | --------------------------- |
| This   | Este/Esta                   |
| That   | Esse/Essa/Aquele/Aquela     |
| These  | Estes/Estas                 |
| Those  | Esses/Essas/Aqueles/Aquelas |

Exemplos:

* **This** is my phone.
* **Those** are my books.

---

## 6. Pronomes interrogativos (Interrogative Pronouns)

| Inglês | Português     |
| ------ | ------------- |
| Who    | Quem          |
| Whom   | Quem (objeto) |
| Whose  | De quem       |
| Which  | Qual          |
| What   | O que / Qual  |

Exemplos:

* **Who** is she?
* **What** is your name?
* **Which** one do you prefer?

---

## 7. Pronomes relativos (Relative Pronouns)

| Inglês | Português            |
| ------ | -------------------- |
| Who    | Que / Quem (pessoas) |
| Whom   | Quem                 |
| Whose  | Cujo(a)              |
| Which  | Que (coisas)         |
| That   | Que                  |

Exemplo:

* The man **who** called me is my teacher.

---

## 8. Pronomes indefinidos (Indefinite Pronouns)

Alguns dos mais comuns:

* Someone (alguém)
* Anyone (qualquer pessoa / alguém)
* Everyone (todos)
* Nobody (ninguém)
* Everything (tudo)
* Nothing (nada)
* Something (alguma coisa)
* Anything (qualquer coisa)

Exemplos:

* **Someone** is at the door.
* **Nobody** knows the answer.

---

### Os pronomes que você mais usará no dia a dia

Se você está começando no inglês, memorize primeiro estes:

* **I** (eu)
* **You** (você)
* **He** (ele)
* **She** (ela)
* **It** (ele/ela para objetos e animais)
* **We** (nós)
* **They** (eles)

Depois aprenda suas formas de objeto e posse:

| Sujeito | Objeto | Possessivo (adjetivo) | Possessivo (pronome) |
| ------- | ------ | --------------------- | -------------------- |
| I       | Me     | My                    | Mine                 |
| You     | You    | Your                  | Yours                |
| He      | Him    | His                   | His                  |
| She     | Her    | Her                   | Hers                 |
| It      | It     | Its                   | —                    |
| We      | Us     | Our                   | Ours                 |
| They    | Them   | Their                 | Theirs               |

Essa tabela reúne cerca de **90% dos pronomes usados em conversas cotidianas em inglês**. Dominar essas formas já permite compreender e formar uma grande variedade de frases.
